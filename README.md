# gerenciamento-de-frota-de-veiculos
Projeto de Jayr

# Definição do projeto
O projeto objetiva a criação de um sistema para gerenciar a frota de veículos de uma empresa de transportes.

## Funcionalidades do Projeto
O sistema deve permitir:
 -cadastro de veículos; 
 -controle de manutenções; 
 -alocação de motoristas; 
 -registro de abastecimentos; 
 -cálculo de custos médios; 
 -relatórios de desempenho

## Aplicação de Conhecimentos Teóricos da Disciplina:
O sistema deve aplicar conceitos de: 
 -encapsulamento; 
 -herança (simples e múltipla); 
 -métodos especiais; 
 -regras de negócio configuráveis. 
 -Persistência em JSON, com um repositório desacoplado do domínio;
